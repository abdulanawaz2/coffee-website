# ☕ Coffee Heaven Website

A modern and responsive coffee shop website built using HTML, CSS, and JavaScript.

##  Features

- Beautiful coffee-themed design
- Responsive layout
- Interactive order button
- Simple and clean UI
- Beginner-friendly project

## Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

coffee-heaven/
│── index.html
│── style.css
│── script.js
│── images/

##  How To Run

1. Download or clone the repository
2. Open project folder in VS Code
3. Run `index.html` in browser
